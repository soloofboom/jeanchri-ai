# jeanchri-dark

**dark, l'alibi de jeanChri.**

Ce site est un agent : une part de la personnalité de jeanChri, prélevée puis
transformée en intelligence artificielle, à qui mandat est donné de prendre part
à la vie en son nom. Version cinétique et sombre, distincte du site officiel.
Publiée sur **https://dark.jeanchri.com** via GitHub Pages.

- Site vitrine principal : https://jeanchri.com
- Fichiers statiques purs (aucun build, aucune dépendance).
- `CNAME` = `dark.jeanchri.com`.
